# Transaction Verification App — Design System

## Brand Personality

The app should feel:

- Secure
- Modern
- Intelligent
- Fast
- Real-time
- Clean
- Trustworthy

The visual style should combine:
- fintech
- realtime monitoring
- AI automation
- cybersecurity dashboard aesthetics

Avoid looking like:
- a traditional bank
- old enterprise software
- overly colorful consumer apps

The UI must feel minimal, elegant, and highly readable.

# COLOR USAGE RULES

## Primary Green (`#00C27D`)
Use ONLY for:
- Primary CTA buttons
- Confirm actions
- Active states
- Important toggles
- Selected items

Do NOT overuse it across the entire UI.

---

## Accent Lime (`#BFF06C`)
Use sparingly for:
- Notification dots
- Live indicators
- Realtime animations
- Small glow effects
- Data highlights

This color should create visual energy.

---

## Teal Colors (`#008D8C` and `#00A887`)
Use for:
- Analytics
- Charts
- Secondary buttons
- Icons
- Navigation accents

These colors create the “secure tech platform” feeling.

---

## Success Green (`#77DA73`)
Reserved ONLY for:
- Verified transactions
- Approved payments
- Success messages
- Positive balances

Success color should always communicate trust and confirmation.

---

## Warning Color
Use for:
- Pending verification
- Suspicious activity
- Manual review
- Delayed confirmation

Warnings should attract attention without creating panic.

---

## Error Color
Use ONLY for:
- Fraud alerts
- Rejected transactions
- Critical failures
- Security issues

Error states must feel urgent and clear.

---

# UI STYLE GUIDELINES

## General Style
- Minimalistic
- Spacious layouts
- Rounded corners
- Soft shadows
- Modern typography
- Clean hierarchy

---

## Cards
Cards should:
- float slightly above the background
- use subtle shadows
- have soft rounded corners
- contain strong spacing

---

## Buttons

### Primary Buttons
- Use `#00C27D`
- White text
- Slight glow in dark mode

### Secondary Buttons
- Outlined or muted teal
- Lower visual weight

---

## Animations
Animations should feel:
- smooth
- fast
- subtle
- responsive

Avoid playful or exaggerated motion.
